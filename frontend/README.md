# Frontend

## Ambiente

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`

Copie `.env.example` para `.env` quando precisar alterar a URL da API.

## Rotas Principais

- `/`: Página inicial com visão geral do sistema e atalhos.
- `/receitas`: Exploração de receitas com busca por nome, filtro de categorias e ordenação por avaliação (US03 e US05).
- `/receitas/nova`: Formulário para publicação de nova receita.
- `/amigos`: Gerenciamento de amizades e solicitações (US08).
- `/cadastro`: Cadastro de novos usuários (US01).
